# PixelPDF Final Android Project

هذا هو المشروع النهائي والمصلح بالكامل.

## المميزات المدمجة:
1. **دعم اختيار ملفات متعددة**: يمكنك اختيار العديد من الصور في وقت واحد دون انهيار التطبيق.
2. **تحميل الملفات آلياً**: يدعم تحميل ملفات الـ PDF والـ Blobs وحفظها في مجلد Downloads بالهاتف.
3. **ذكاء اللغة**: رسالة "تم الحفظ" تتغير تلقائياً حسب اللغة المختارة في التطبيق (AR/EN/FR).
4. **جاهز لـ GitHub Actions**: بمجرد رفع الملفات، سيقوم GitHub ببناء الـ APK لك.

## طريقة الاستخدام:
1. ارفع هذه الملفات لمستودع جديد على GitHub.
2. اذهب لـ Actions وحمل الـ APK الناتج.
3. قم بتوقيع الـ APK باستخدام تطبيق "APK Signer" على هاتفك قبل النشر في متجر هواوي.
