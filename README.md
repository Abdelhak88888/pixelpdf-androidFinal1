# PixelPDF Android App (GitHub Actions Build)

هذا المستودع جاهز تماماً لتحويل صفحة الـ HTML (`index.html`) إلى تطبيق **APK** لأجهزة أندرويد عبر **GitHub Actions** بشكل تلقائي 100% ودون الحاجة لتثبيت Android Studio على حاسوبك.

## مميزات هذا التغليف:
1. **أزرار رفع الملفات (Upload / Add Files)** تعمل بشكل كامل بفضل ربط `WebChromeClient.onShowFileChooser`.
2. **أزرار التحميل والتنزيل (Download)** تعمل بشكل كامل بفضل ربط `DownloadListener`.
3. **التصميم الأصلي** لصفحتك محتفظ به تماماً ويعمل داخل تطبيق WebView عالي الأداء.

---

## 🚀 طريقة الاستخدام في غيت هوب (GitHub):

1. أنشئ مستودعاً جديداً (Repository) على غيت هوب (مثلاً باسم `pixelpdf-app`).
2. قم برفع جميع الملفات الموجودة في هذا المجلد (بما في ذلك مجلد `.github` و `app` وباقي الملفات) إلى المستودع.
3. اذهب إلى تبويب **Actions** في مستودعك على غيت هوب.
4. سترى أن عملية البناء (`Build Android APK`) بدأت تلقائياً! (أو يمكنك الضغط على `Run workflow`).
5. انتظر دقائق معدودة حتى تنتهي العملية بنجاح (علامة صح خضراء ✅).
6. اضغط على البناء المكتمل، ثم انزل إلى أسفل الصفحة في قسم **Artifacts** وحمل ملف `PixelPDF-Debug-APK.zip`.
7. فك الضغط عن الملف لتحصل على ملف **`app-debug.apk`**، قم بتثبيته على هاتفك واستمتع بالتطبيق!
